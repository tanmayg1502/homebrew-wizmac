# homebrew-wizmac

Homebrew tap for Wizmac.

Install with:

```bash
brew tap tanmayg1502/wizmac
brew install wizmac
```

Or install the full packaged app with:

```bash
brew tap tanmayg1502/wizmac
brew install --cask wizmac
```

This tap distributes:

- a formula for the public `wizmac` CLI and `WizmacService`
- a cask for the packaged `Wizmac.app`

Public release assets are hosted in `tanmayg1502/wizmac-releases`.
